Cloudflare Workers is a serverless execution environment that allows you to create new applications or augment existing ones without configuring or maintaining infrastructure. Workers run on Cloudflare's edge network in over 300 cities around the world. This means your code runs close to your users, resulting in low latency and fast response times. Vectorize is Cloudflare's vector database product, designed to work natively with Workers AI embeddings. It supports cosine similarity search and can store millions of vectors. R2 is Cloudflare's object storage solution with zero egress fees, compatible with the S3 API.
